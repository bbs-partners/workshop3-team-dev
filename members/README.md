# members フォルダ

事前課題で、ここに自分のファイルを追加してください。

## やり方

`あなたの名前.md` というファイルを作って、簡単な自己紹介を書きます。

例：`yamada.md`
```
山田太郎 / 営業部 / よろしくお願いします
```

## コマンド例

```bash
echo "山田太郎 / 営業部 / よろしくお願いします" > members/yamada.md
git add members/yamada.md
git commit -m "add: 山田のメンバーファイルを追加"
git push
```

これができたら事前課題は完了です。
